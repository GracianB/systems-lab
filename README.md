# 01 · THE LAB

**Systems Lab** es el mundo técnico de [GracianB](https://gracianb.github.io/GracianB/).

Aquí no presento solamente proyectos.

Presento **sistemas que se pueden tocar**.

Interfaces. Automatizaciones. Experimentos. Agentes. Juegos. Visualizaciones. Prototipos. Sistemas de Customer Success.

La regla es deliberadamente sencilla:

> **No te lo explico. Púlsalo.**

Y otra:

> **Live = se abre ahora.**

Porque un README diciendo *“this project demonstrates...”* es una forma elegante de decir que todavía no sabes qué hacer con él.

### [→ ABRIR SYSTEMS LAB](https://gracianb.github.io/systems-lab/)

# 07 · METHOD

## BUILD → TEST → BREAK → FIX → SHIP

No intento construir todo perfecto desde el primer commit.

Construyo.

Lo pruebo.

Lo rompo.

Descubro por qué.

Lo arreglo.

Lo vuelvo a probar.

Y finalmente lo publico.

```text
IDEA
 ↓
PROTOTYPE
 ↓
TEST
 ↓
FAIL
 ↓
DEBUG
 ↓
ITERATE
 ↓
SHIP
 ↓
LEARN
 ↺
```

La iteración no es un accidente del proceso.

**Es el proceso.**

# 12 · WHY THIS LAB EXISTS

Hay una diferencia entre:

> **“Sé utilizar esta tecnología.”**

y:

> **“Sé convertir un problema en un sistema que utiliza esta tecnología.”**

Me interesa mucho más la segunda.

Por eso este laboratorio mezcla deliberadamente:

**Customer Success + Data + AI + Automation + Development + Systems**

No para acumular tecnologías.

Para construir cosas que hagan algo.
